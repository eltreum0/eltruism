## About

**Eltruism** is a feature-rich ElvUI plugin that extends ElvUI with extensive customizations, signature gradients, combat voice alerts, and tailored interface profiles for World of Warcraft.

Both the **DPS/Tank** profile and the **Healer** profile are handcrafted for 16:9 displays and thoroughly tested across 1080p, 1440p, 4K, and Ultrawide resolutions.

Every single feature in Eltruism is **100% modular** and can be toggled on or off to match your personal preference.

> [!IMPORTANT]
> Eltruism is an ElvUI plugin and requires **[ElvUI](https://www.tukui.org/download.php/ui=elvui)** to function.

## Features

- **Dual Tailored Profiles:** Dedicated DPS/Tank and Healer layouts with pixel-perfect unitframes, actionbars, and raid anchors.
- **Signature Gradients:** Silky smooth color gradients across Unitframes, Blizzard Raid Frames, Nameplates, and Aurabars with Lua-cached performance.
- **Audio & TTS Voice Alerts:** Text-To-Speech announcements for offensive/defensive cooldowns, interrupts, and low health/mana warnings.
- **Dynamic Nameplates:** Dynamic height scaling, threat-colored borders, integrated power bars, and debuff highlighting.
- **Cursor HUD:** Rotating HUD rings anchored to your cursor indicating cast time progress, GCD, and cooldown timers.
- **Actionbars & Glows:** Customizable spell activation and proc glow animations with bespoke speeds, plus Shaman totem tracker glows in Classic.
- **Sleek Themes & Skins:** Soft shadows, dark & light themes, custom class textures, role icons, and reskinned Character Panel, Quests, and companion AddOns.
- **Transparent Unitframe Health:** Quickly toggle sleek transparent unitframe health backgrounds via `/eltruism transparent`.
- **Navigation & Waypoints:** Enhanced `/way` command with real-time distance calculations, ETA arrival estimation, and navigation arrow tracking.
- **Instant Fast Loot & Wishlist:** True instant auto-looting with zero window lag, movable LootText alerts, junk vendor automation, and personal loot wishlist tracking.
- **Chat Enhancements:** Inline item icons in chat links, smooth chat fade, and the `!keys` shortcut to share your Mythic+ dungeon keystone.
- **Combat & AFK Immersion:** Contextual combat music playlists, relaxing AFK screen with 3D character models and music, and bespoke mail arrival sounds.
- **Unified Castbars:** Unified player, target, and focus castbars with dedicated interrupt protection shields and timer tags.
- **Multi-Expansion & Modular:** Actively maintained for Retail, MoP, Wrath, Classic Era, and WoW Forever.

## Installation

1. **Install ElvUI:** Download and extract the latest version of **[ElvUI](https://www.tukui.org/download.php/ui=elvui)** into your World of Warcraft `_retail_/Interface/AddOns` (or classic equivalent) folder.
2. **Download Eltruism:** Install Eltruism via the **[CurseForge App](https://www.curseforge.com/wow/addons/elvui-eltruism)**, **[Wago App](https://addons.wago.io/addons/elvui-eltruism)**, or manually from **[GitHub Releases](https://github.com/eltreum0/eltruism/releases)**.
3. **Run In-Game Installer:** Launch World of Warcraft. The setup installer will greet you automatically, or you can open it at any time by typing `/eltruism` in chat.

## Chat Commands

All primary configuration and utilities can be accessed via `/eltruism`:

### General & Setup

| Command | Action |
| :--- | :--- |
| `/eltruism` *(or `/eltruism config` / `/eltruism options`)* | Opens the Eltruism configuration options menu |
| `/eltruism setup` *(or `/eltruism install` / `/eltruism installer`)* | Opens the Eltruism setup installer |
| `/eltruism update` | Resets/updates Eltruism settings to Eltreum's official defaults |
| `/eltruism autoupdate` | Toggles automatic updating of Eltruism settings when updating versions |
| `/eltruism elvuiskin` | Toggles the Eltruism ElvUI skin template |
| `/eltruism weakauras` | Toggles ActionBars, UnitFrames, and Powers layout to be similar to WeakAuras |
| `/eltruism paging` `[1-9]` | Swaps Actionbar paging between Bar 1 and Bar 4, or switches to a specific bar |

### Visuals & Themes

| Command | Action |
| :--- | :--- |
| `/eltruism transparent` | Toggles unitframes transparent health mode on/off |
| `/eltruism color` | Toggles unitframes between light and dark modes |
| `/eltruism gradient` | Toggles unitframe and interface gradient mode |
| `/eltruism chat` | Toggles chat window between dark and transparent modes |
| `/eltruism background` | Toggles unitframe background between grey and black |
| `/eltruism autoadjust` | Toggles borders automatically adjusting the layout for DPS & Healer profiles |
| `/eltruism togglemodels` | Toggles 3D portrait character models on/off |

### Gameplay & Convenience

| Command | Action |
| :--- | :--- |
| `/eltruism detailshide` | Toggles automatically hiding Details! damage meter out of combat |
| `/way <x> <y> [title]` *(or `/waypoint`)* | Sets a map waypoint coordinate with distance, ETA, and arrow navigation |
| `/eway <x> <y> [title]` *(or `/ewaypoint`)* | Sets a map waypoint (used when TomTom is detected to avoid command conflicts) |
| `!keys` *(or `!key`)* | Links your active Mythic+ or Delve keystone to party, guild, or raid chat |

### Performance & Utilities

| Command | Action |
| :--- | :--- |
| `/eltruism performance` | Optimizes performance by applying CVars and disabling heavy functions |
| `/eltruism performancecvars` | Applies CVars to optimize client performance and framerates |
| `/eltruism encountercheck` | Toggles disabling non-essential functions during boss encounters |
| `/eltruismdebug on` / `off` | Toggles debug mode (disables third-party addons and enables Lua script errors) |
| `/eltruism screenshotcomparison` | Automatically captures sequential screenshots across Native, 720p, 1080p, 1440p, and 4K |
